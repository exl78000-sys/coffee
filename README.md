# ☕ 咖啡沖煮記錄器

一個在手機上就能用的咖啡沖煮筆記 App（PWA）。幫你記錄每支豆子的最佳沖法、手沖分段水量與手法、水粉比，以及不同磨豆機之間的刻度換算。支援 **手沖、浸泡式（法壓／聰明濾杯／愛樂壓）、義式、摩卡壺**。

不需要安裝任何套件、不需要帳號，資料存在你自己的瀏覽器裡，可離線使用。

## 功能

### 沖煮記錄
- 沖煮法：手沖／浸泡式／義式／摩卡壺，各自有對應欄位
  - 手沖：濾杯、濾紙、水溫、**分段注水**：每段只要填「注水幾克」和「這段結束的秒數」，自動算累計；段落名稱與手法為選填（按 ⋯ 展開）
  - 義式：粉量 → 萃取量（出液比）、萃取時間、水溫、預浸泡、壓力、粉碗
  - 摩卡壺：粉量、水量、注入熱水或冷水、火力、開始流出時間
- **粉量／水粉比／水量三向連動**：改粉量或比例會自動算水量；直接改水量會反推比例
- 分段水量可「隨總水量等比例調整」，改粉量時每一段會自動縮放
- 預設只有一段，按「＋ 手動新增」加段；也可以選用範本：
  - **大師配方**：James Hoffmann 終極 V60、Hoffmann 單杯 V60、粕谷哲 4:6 法、Origin Coffee V60、Hoffmann 愛樂壓、Hoffmann 法壓壺。套用時保留原配方的水粉比與時間點，依你的粉量等比例換算水量，並附上來源連結
  - **通用**：三段式、一刀流、浸泡
- 「工具 → 配方庫」可以瀏覽所有大師配方，直接「跟著計時」或「用這個配方新增記錄」
- **建議分段**：填好粉量、水量後按「建議分段」，再手動調整。依據會寫在畫面上，順序是：
  1. 這支豆子的最佳配方（或評分最高的一杯）
  2. 同烘焙度豆子裡 4 星以上的一杯（處理法相同優先）
  3. 通用經驗法則，可指定 60/40、4:6、平均三段：悶蒸約粉量 2 倍、30–45 秒；目標總時間 15g 約 3:00、每多 5g 加約 10 秒；水溫依烘焙度
- **目標時間與研磨建議**：存檔時比較實際總時間和目標，差超過 15 秒就提示下次磨粗或磨細
- **不同次對比**：記錄頁「跟上一杯比」列出改了哪些參數；豆子頁「對比記錄」把同一支豆子的每一杯並排，跟前一杯不同的格子會標出來
- 評分（1–5 星）、酸／甜／苦／醇厚、風味描述、心得、**下次調整**
- 「再沖一次」複製上一杯的參數；可把某一杯設為這支豆子的 **★ 最佳配方**（依沖煮法分開）

### 豆子
- 烘豆商、產區、品種、處理法、烘焙度、烘焙日、重量、價格、風味標示
- **拍照記規格**：拍下包裝標籤存成照片；在 claude.ai 頁面上會請 Claude 讀取標籤，自動填入空白欄位
- 新增記錄時豆子、磨豆機都可以直接打字輸入，新名稱可勾選「加入常用」自動建立（輸入常見磨豆機型號會帶入換算參考值）
- 自動計算**養豆天數**與**剩餘豆量**（重量 − 已用粉量）
- 每支豆子顯示各沖煮法的最佳配方，一鍵「跟著計時」或「用這個配方再沖」
- 新增記錄時選了豆子，會提醒你**上次寫的「下次調整」**，並可套用最佳配方

### 計時沖煮
- 跟著記錄的分段計時：大字顯示目前段落、要注多少水、累計到幾克、手法
- 顯示這段要在幾秒結束、還剩幾秒；換段時提示音＋震動，結束前 3 秒倒數嗶聲；計時中保持螢幕不關閉
- 「自由計時」：每段注水結束時按「這段結束」，完成後自動帶入各段結束秒數

### 工具
- **水粉比換算**：已知粉量求水量、已知水量求粉量，附 1:13–1:18（義式 1:1.5–1:3）對照表
- **配方縮放**：把某杯配方改成不同粉量，各段水量等比例換算
- **研磨換算**：
  - 把 A 磨豆機的刻度換成 B 磨豆機的刻度
  - 每台磨豆機在義式／摩卡壺／愛樂壓／手沖／法壓／冷萃的建議刻度範圍
  - **同杯校正**：兩台磨出來口感一樣時記下各自刻度，讓換算更貼近你手上的機器
  - 新增記錄時換磨豆機，刻度會自動換算

### 設定
- 磨豆機管理，內建常見手搖磨（Comandante C40、1Zpresso JX-Pro / K-Ultra / K-Max、Kingrinder K6）的參考值
- 匯出／匯入 JSON 備份（可合併或取代）
- 載入範例資料先試玩

## 研磨換算怎麼算

以線性模型近似：

```
粒徑 (µm) ≈ 零點偏移 + 每格微米 × 刻度（從歸零起算的總格數）
```

內建的每格微米與各沖煮法的粒徑範圍都是常見參考值，實際會因豆子、烘焙度、刀盤磨合而不同，**請當作起點，再用口感微調**。若你知道兩台磨豆機的對應刻度，用「工具 → 研磨換算 → 同杯校正」會更準。

## 使用方式

App 有三種版本，介面一樣，差在資料存哪裡：

| 版本 | 資料存在 | 適合 |
|---|---|---|
| **Google 試算表版（建議）** | 你自己的 Google 試算表，一列一筆，可以直接打開看 | 長期使用、資料自己掌控 |
| claude.ai 頁面版 | claude.ai 頁面的雲端資料庫 | 想用「拍照自動讀取豆子規格」 |
| 一般網頁版 | 該裝置瀏覽器的 localStorage | 試玩、離線 |

### 存到 Google 試算表（建議）

需要用**電腦**做一次設定，大約 3 分鐘，只要貼一個約 230 行的檔案。App 的頁面會自動從這個 GitHub repo 讀取，所以 repo 要保持**公開**。

1. 打開 <https://sheets.new> 建立新試算表，取名「咖啡沖煮記錄」。
2. 選單「**擴充功能 → Apps Script**」。
3. 把編輯器裡 `程式碼.gs`（Code.gs）的內容全部刪掉，貼上本 repo 的 [`gas/Code.gs`](gas/Code.gs)（打開後按右上角「Copy raw file」圖示可一次複製）。
4. 按儲存（磁碟圖示）。
5. 右上「**部署 → 新增部署作業**」，左邊齒輪選「**網頁應用程式**」：
   - 執行身分：**我**
   - 誰可以存取：**只有我自己**
   - 按「部署」。
6. 第一次會要求授權：選你的帳號 → 允許。若出現「Google 尚未驗證這個應用程式」，點「進階 → 前往…（不安全）」。這是你自己的程式，權限只有「這一份試算表」和「連線到外部服務」（用來從 GitHub 讀取 App 頁面）。
7. 複製「網頁應用程式」的網址，用手機打開，加入書籤或主畫面。

之後在 App 裡新增的豆子、磨豆機、沖煮記錄會出現在試算表的「豆子」「磨豆機」「沖煮記錄」分頁。

- 可以直接在試算表修改文字和數字（例如補寫心得），下次打開 App 就會讀到。
- 最右邊的「其他資料（請勿修改）」欄存的是分段等細節，請不要改。
- 「豆子」「分段」這類摘要欄只是方便閱讀，改了不會被讀回。
- 照片存在隱藏的「_照片」分頁。
- 可以自己加欄位，App 不會動它。

**更新程式**：App 頁面會自動跟著 GitHub 更新（最多延遲約一小時；在網址後面加 `?refresh=1` 可以立刻更新）。只有 `Code.gs` 本身改了才需要重貼，貼完到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址不變。

**從其他版本搬資料**：在舊版本「設定 → 匯出備份」，在試算表版「設定 → 匯入」。

### 發佈成 claude.ai 頁面
`npm run build` 會產生 `dist/coffee-log.html`，可以發佈成 claude.ai 的私人頁面。資料存在頁面的雲端資料庫；這個版本可以拍照後請 Claude 讀取豆子規格自動填入。

### 一般網頁版
直接用瀏覽器打開 `index.html`，或 `npm start` 後打開 <http://localhost:8000>。資料只存在該裝置的瀏覽器中，換裝置前請先匯出備份。

## 開發

純 HTML / CSS / JavaScript。一般網頁版不用建置；改完程式後執行 `npm run build` 重新產生試算表版與 claude.ai 版的單一檔案。

```
index.html            頁面骨架與底部導覽
css/style.css         樣式（含深色模式）
js/calc.js            純計算：水粉比、分段縮放、研磨換算、範本（可在 Node 測試）
js/store.js           資料層（Google 試算表 / claude.ai 頁面資料庫 / localStorage、匯入匯出）
gas/Code.gs           Google 試算表版的伺服器端（Apps Script）
gas/Index.html        Google 試算表版的頁面（由 npm run build 產生，Code.gs 從 GitHub 讀取它）
scripts/build.js      打包成單一 HTML：dist/coffee-log.html 與 gas/Index.html
js/app.js             各頁面畫面與互動
sw.js                 離線快取（修改檔案後請調整 VERSION）
tests/                計算、試算表欄位對應、Apps Script 後端的單元測試
```

執行測試：

```bash
npm test
```

## 之後可以加的
